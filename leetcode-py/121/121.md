在遍历每一天的价格时，我们只需要关注两件事：

历史最低点 (min_price)：截至当前，我能买入的最低价格是多少？

当前最大利润 (max_profit)：如果我在那个“历史最低点”买入，并在“今天”卖出，能赚多少钱？如果比之前的利润高，就更新最大利润。


### Solution

```python
from typing import List

class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        # 如果数组为空或只有一个元素，无法交易
        if not prices or len(prices) < 2:
            return 0
            
        min_price = float('inf')  # 初始化为一个无穷大的数
        max_profit = 0            # 初始化利润为 0
        
        for price in prices:
            # 1. 找到更低的价格，更新买入点
            if price < min_price:
                min_price = price
            # 2. 如果当前价格卖出比之前的利润高，更新最大利润
            elif price - min_price > max_profit:
                max_profit = price - min_price
                
        return max_profit
```
